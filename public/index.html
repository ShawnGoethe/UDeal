🔌 MCP 接入 — Agent 集成指南

UDeal 支持标准 MCP (Model Context Protocol) 协议，任何兼容 MCP 的 AI Agent（如 Claude Desktop、OpenClaw 等）均可接入，查询会员权益、筛选对比、记录使用情况。

1. 连接配置

// claude_desktop_config.json 或 .mcp.json
      {
        "mcpServers": {
          "udeals": {
            "url": "https://udeals.utools.icu/mcp"
          }
        }
      }

启动入口：dist/mcp/stdio.js（stdio 传输模式）

2. 可用工具

🔍 search_benefits
搜索权益，支持关键词+多维筛选
query (必填) 搜索词   tag 标签ID   platform 平台ID   type free|paid
📋 list_platform_benefits
列出指定平台的全部权益
platform_id (必填) 如 meituan, jd, taobao-88vip
🏷️ get_categories
获取所有分类和标签（用于构建筛选 UI）
无参数

3. 筛选方式

使用 search_benefits 时可组合以下筛选维度：

维度参数示例值
关键词query"洁牙"、"外卖"、"贵宾厅"
标签tagdental-cleaning, airport-lounge, food-delivery
平台platformmeituan, jd, taobao-88vip
类型typefree（免费权益）、paid（付费权益）

💡 先调用 get_categories 获取所有可用的标签 ID 和分类 ID。

4. Agent 使用记录

Agent 可通过memory记录使用情况

5. Agent 调用示例

// 用户: "我有哪些免费的洁牙权益？"
Agent → search_benefits(query="洁牙", type="free")
← 返回各平台免费洁牙权益列表

// 用户: "美团黑金会员有什么权益？"
Agent → list_platform_benefits(platform_id="meituan")
← 返回美团全部权益（含等级详情）

// 用户: "帮我记录一下，我是美团黑金会员"
Agent → update_membership(platform_id="meituan", level="黑金", since="2025-01-01")
← 确认已记录

// 用户: "我现在的会员权益有哪些？"
Agent → get_my_benefits()
← 返回已记录会员的可用权益

// 用户: "哪个平台的机场贵宾厅最好？"
Agent → compare_benefits(query="机场贵宾厅")
← 跨平台对比贵宾厅权益

// 用户: "有什么快到期的会员吗？"
Agent → get_expiring_soon()
← 返回 30 天内到期的会员列表
